### 序言

#### 第三版序

大学期间我也和上一本手册的主要编写者孙学长联系上了，同时也得到了他的一些宝贵意见和建议。本手册将不会频繁更新，至多每一年到两年进行一次修订，尽量把一些有趣生动的内容传递给学弟学妹。

**本次修订将有两个非常重大的变化！**

第一个是**项目将转入GitBook托管**，便于访问和查看，同时与原GitHub仓库保持同步。同时，有计划设计GitHub Actions以自动渲染本项目的PDF，便于传播。

第二个是本项目将进行近年来**较大幅度的结构调整**。我会带领电脑社的学弟学妹和其他的学弟学妹对项目的结构做一次大调整。同时删去本人高中时期写的一些很中二的私货。

合一已经不是我在读的时候只有一个校区的“小学校”了，而是一个拥有四大主校区和许多集团校的庞大教育集团。**也需要说明，这里的内容仅适用于四大主校区。**

几年来，人工智能技术给这个世界带来了巨大的变革，也正在重塑科研、学习、工作的范式，但也让我们不禁思考学习的意义、活着的意义。我想借用《流浪地球2》当中的一句话，“没有人的文明毫无意义”，一切都是要围绕着人类本身来讨论的。高中生活恐怕也不只是为了高考，那样可太做题家了！人可不能同时拥有青春和对青春的感受，时至今日我还是觉得自己在合一的生活太干瘪了，远没有我的同学和学弟学妹们那么精彩。除了高考成绩，还应该在高中三年培育什么样的能力，让自己成为什么样的人，是你更应该思考并与同伴、前辈、老师、家长讨论的问题。

希望学弟学妹能成为身心健康、人格健全的人，“怀天下抱负，做未来主人”。无论未来你的发展如何，无论你去到哪里，合一应该都是你人生中不可或缺的那一抹底色；如果在别处遇到校友，也许你也会会心一笑。

祝大家在合一生活愉快！

——Chloridy, 2026.9 于合肥
